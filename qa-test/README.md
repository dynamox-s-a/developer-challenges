# QA Automation Test – Dynamox

## Prerequisites

Before running the tests you must have installed:

* Python 3.10+
* pip
* Git

## Setup

Install project dependencies:

pip install -r requirements.txt

Install Playwright browsers:

rfbrowser init

## Run tests

robot -d results tests/
