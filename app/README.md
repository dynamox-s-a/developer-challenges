# Dynamox Dashboard

Projeto front-end inicializado com Vite e as dependências do desafio Dynamox.

## Stack

- **Vite** — build tool
- **React** + **TypeScript**
- **Redux Toolkit** + **Redux Saga**
- **Material UI 5**
- **Highcharts**
- **Jest** + Testing Library

## Pré-requisitos

Node.js 20+ (use `nvm use` na pasta do projeto).

## Scripts

```bash
npm install
npm run dev      # servidor de desenvolvimento
npm run build    # build de produção
npm run test     # testes unitários
npm run preview  # preview do build
```

## Estrutura

```
src/
  app/           # Redux store, sagas e hooks tipados
  theme.ts       # tema Material UI
  setupTests.ts  # configuração global do Jest
```
